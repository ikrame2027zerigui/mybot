# 🌿 بوت مدون الإكرام (Al-Ikram Transcriber & Academic Assistant)

بوت تيليجرام متكامل ومساعد دراسي ذكي لطلبة العلوم الإسلامية والدراسات الجامعية، يجمع بين أدوات التفريغ الصوتي التلقائي للمحاضرات، وبنك الأسئلة التفاعلي، والترجمة الفورية، وإدارة الجداول الدراسية.

---

## ✨ المميزات الرئيسية

* 🎙️ **تفريغ صوتي احترافي للمحاضرات:**
  * دعم المقاطع الصوتية والتسجيلات المباشرة مهما كان حجمها أو مدتها.
  * تقسيم ذكي ومعالجة متقدمة عبر محرك `Google Speech` و `FFmpeg`.
  * استخراج فوري لمستند Word منسق (`.docx`) وملف نصي خفيف (`.txt`) مع توليد عنوان وملخص للمحاضرة.

* 🧠 **بنك الأسئلة والاختبارات الذاتية:**
  * أسئلة تفاعلية بنظام الخيارات مع الشرح والتصحيح الفوري في: (أصول الفقه، مصطلح الحديث، القواعد الفقهية، علوم القرآن، مقاصد الشريعة، والفقه المقارن).

* 🌐 **محرك ترجمة سحابي فائق الاعتمادية:**
  * يدعم الترجمة بين العربية والإنجليزية والفرنسية والتركية والروسية مع حماية ضد الحظر واستجابة فورية.

* 🚀 **دعم الملفات الكبيرة حتى 2GB:**
  * تكامل مع خادم `telegram-bot-api` المحلي لتجاوز حد الـ 20MB / 50MB الافتراضي في تيليجرام.

* ⏱️ **خادم Keep-Alive (يعمل 24/7):**
  * خادم ويب داخلي مدمج عبر Flask لإبقاء البوت نشطاً باستمرار على منصات الاستضافة السحابية مثل Render.

* 📊 **نظام إدارة المشرف والإحصائيات:**
  * إشعارات تلقائية فورية للمشرف عند انضمام طالب جديد، وإمكانية إرسال رسائل جماعية (Broadcast) لجميع الطلاب.

## 📁 هيكلية المشروع

```text
├── .env.example        # نموذج متغيرات البيئة السرية
├── .gitignore          # استثناء الملفات المؤقتة والسرية من الرفع
└── README.md           # دليل الاستخدام والتوثيق
```

## ⚙️ متطلبات التشغيل

1. **Python 3.10** أو أحدث.
2. **أداة FFmpeg** مثبتة في مسار النظام (ضرورية لمعالجة وتحويل الصوتيات):
   * **Ubuntu/Debian:** `sudo apt-get install ffmpeg`
   * **Windows:** تثبيتها عبر `winget install Gyan.FFmpeg` أو تحميلها وإضافتها لـ PATH.

---

## 🚀 التشغيل المحلي (Local Setup)

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/ikrame2027zerigui/mybot.git
   cd mybot
   ```

2. **إنشاء وتفعيل بيئة افتراضية (اختياري ولكن يُنصح به):**
   ```bash
   python -m venv venv
   # على Linux/macOS:
   source venv/bin/activate
   # على Windows:
   venv\Scripts\activate
   ```

3. **تثبيت المكتبات:**
   ```bash
   pip install -r requirements.txt
   ```

4. **إعداد متغيرات البيئة:**
   * أنشئ ملف `.env` وانسخ محتويات `.env.example`:
   ```bash
   cp .env.example .env
   ```
   * ضع توكن البوت الخاص بك من [@BotFather](https://t.me/BotFather):
   ```env
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuVWXyz
   ADMIN_ID=6619712661
   PORT=8080
   ```

5. **تشغيل البوت:**
   ```bash
   python BOT.py
   ```

## 🐳 التشغيل عبر Docker

يحتوي ملف `Dockerfile` على بيئة جاهزة تتضمن بايثون، و FFmpeg، وخادم `telegram-bot-api` المباشر:

```bash
# بناء الصورة
docker build -t mybot .

# تشغيل الحاوية
docker run -d --name mybot-container --env-file .env -p 8080:8080 mybot
```

---

## ☁️ النشر على Render أو السيرفرات السحابية

1. اربط حسابك في [Render.com](https://render.com) بمستودع GitHub هذا.
2. أنشئ **Web Service** جديد واختر خيار **Docker**.
3. في قسم **Environment Variables**، أضف:
   * `BOT_TOKEN`: توكن البوت الخاص بك.
   * `ADMIN_ID`: معرف المشرف (مثال: `6619712661`).
   * `PORT`: `8080` (أو المنفذ الافتراضي).
4. اضغط على **Deploy** وسيعمل البوت تلقائياً ومباشرة على مدار الساعة!
