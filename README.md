## 📖 نبذة عن المشروع

**بوت مُدوِّن الإكرام** هو نظام برمجـي وأكاديمي ذكي مبني بلغة **Python** ومخصص لمساعدة طلبة الجامعات عموماً، وطلبة **كلية العلوم الإسلامية (جامعة الجزائر 1 — خروبة)** خصوصاً. 

تم تطوير البوت ليجمع بين أحدث تقنيات الذكاء الاصطناعي ومعالجة الصوتيات، وبين العلوم الشرعية والتأصيل الأكاديمي، موفراً بيئة دراسية متكاملة تغني الطالب عن تشتت التطبيقات؛ بدءاً من تفريغ المحاضرات في ثوانٍ معدودة وتوليد مذكرات Word الأكاديمية والملخصات المركزة، وصولاً إلى المذاكرة التفاعلية عبر بنك أسئلة غير مكرر ومعجم أصولي فوري، كل ذلك داخل واجهة تفاعلية مصغرة (*Telegram Mini App*) راقية ومستوحاة من ألوان المخطوطات والكتب التراثية.

## ✨ المميزات الرئيسية

### 🎙️ 1. التفريغ الصوتي الذكي فائق السرعة (STT Engine)
* **محرك Groq Whisper المسرّع (Fast-Path):** تفريغ التسجيلات الصوتية في 2 إلى 3 ثوانٍ فقط بدقة استماع استثنائية للغة العربية والمصطلحات الشرعية.
* **محرك Pydub + Google STT الاحتياطي:** نظام تبديل تلقائي سلس يضمن استمرار التفريغ حتى عند انقطاع الاتصال بأي مزود خارجي.
* **معالجة وتجزئة المقاطع الطويلة (Audio Chunking):** استخدام مكتبة `FFmpeg` لتجزئة التسجيلات والمحاضرات الطويلة لمعالجتها وعرض نسبة التقدم.
* **المصحح الإملائي الأكاديمي المدمج:** تصحيح آلي فوري للأخطاء الشائعة في تحويل الصوت إلى نص (التاء المربوطة، همزات الوصل والقطع، والمصطلحات الأكاديمية مثل: *خروبة، مقاصد الشريعة، أصول الفقه، نادي جسور*).
* **تصدير مزدوج فوري:**
  * 📄 **مستند Word أكاديمي فاخر (`.docx`):** منسق بغلاف يحمل اسم الطالب، تاريخ المحاضرة، وإحصائية بعدد الكلمات.
  * 📝 **ملف نصي خفيف (`.txt`):** ملائم للقراءة السريعة والمشاركة السريعة عبر الهواتف.
* **دعم اللغات واللهجات:** العربية الجزائرية (`ar-DZ`)، العربية الفصحى (`ar-SA`)، الإنجليزية (`en-US`)، الفرنسية (`fr-FR`)، والروسية (`ru-RU`).

---

### 💡 2. أدوات المحاضرة التفاعلية الذكية (Interactive Lecture Tools)
يُرفق البوت أسفل كل تسجيل يتم تفريغه لوحة أدوات ذكية فورية:
1. **💡 تلخيص في 5 نقاط:** استخراج أهم 5 محاور وقضايا علمية وردت في المحاضرة بنظام هجين يجمع بين ذكاء **Gemini AI** وخوارزمية تحليل التكرارات اللغوية.
2. **📄 مستند Word الأكاديمي:** إعادة تنزيل مستند المحاضرة المنسق في أي لحظة.
3. **🌐 ترجمة المحتوى:** ترجمة المحاضرة أو ملخصها فوراً للغات أجنبية.
4. **🎯 اختبر فهمك للدرس:** توليد سؤال اختبار ذاتي مباشر مبني على مفاهيم التخصص لاختبار استيعاب الطالب لما سمعه.

### 📱 3. واجهة تيليجرام المصغرة الأكاديمية (Telegram Mini App)
* **تصميم راقٍ بألوان المخطوطات والكتب:** واجهة ويب تفاعلية مدمجة داخل تيليجرام مصممة بتدرجات لونية هادئة (الكريمي الناعم `#FFFDF9`، البيج الأكاديمي `#F4ECE1`، والبني المخملي الكلاسيكي `#5C4033`).
* **خطوط عربية أصيلة:** اعتماد خطوط الطباعة العربية الراقية (*Amiri* و *Tajawal*).
* **جسر اتصال فوري (Direct API Bridge):** بمجرد لمس أي بطاقة في الواجهة، يُرسل الأمر مباشرة لسيرفر البوت وتُغلق النافذة بسلاسة مع اهتزاز لمسي خفيف (*Haptic Feedback*) لتبدأ الخدمة في الشات فوراً.
* تفتح الواجهة عبر الزر الثابت أو بأمر `/menu`.

---

### 🧠 4. بنك الأسئلة والمراجعة الذاتية بدون تكرار
* نظام امتحاني ذكي متعدد الخيارات (أ / ب / ج) مع تصحيح فوري وشرح تعليلي لكل مسألة.
* **خوارزمية منع التكرار:** يتتبع البوت تقدم الطالب في الأسئلة ليعرض له دائماً أسئلة جديدة حتى يُتم بنك الأسئلة بالكامل قبل بدء جولة مراجعة ثانية.
* يشمل الأبواب العلمية الأساسية:
  * ⚖️ **أصول الفقه** (الأدلة المتفق عليها والمختلف فيها، دلالات الألفاظ، النسخ، التعارض والترجيح).
  * 📜 **مصطلح الحديث** (شروط الحديث الصحيح، مراتب الحديث، المرفوع والموقوف والمقطوع).
  * 📖 **علوم القرآن** (المكي والمدني، جمع القرآن، رسم المصحف والقراءات).
  * 🏛️ **القواعد الفقهية** (القواعد الخمس الكبرى وفروعها وتطبيقاتها).
  * 🎯 **مقاصد الشريعة** (الكليات الخمس، الضروريات والحاجيات والتحسينيات).
  * 🤝 **فقه المعاملات المالية المعاصرة**.

### 📚 5. المعجم الفقهي والأصولي الرقمي
* وصول فوري بضغطة زر إلى خلاصة التأصيل الشرعي:
  * القواعد الفقهية الكبرى وتطبيقاتها المعاصرة.
  * أدلة أصول الفقه الإجمالية.
  * ضوابط الحديث الصحيح وشروطه الخمسة عند المحدثين.
  * أركان وضوابط القياس (الأصل، الفرع، العلة، الحكم).
  * ضوابط البيوع والمعاملات المستحدثة.

### 🌐 6. محرك الترجمة السحابي المقاوم للحظر (8 طبقات حماية)
* محرك هجين متعدد الطبقات يعتمد ترويسات تطبيق Google Translate الرسمي على أجهزة Android لمنع حظر خوادم مراكز البيانات (*HTTP 429*).
* دعم الترجمة الفورية بين **6 لغات**: العربية، الإنجليزية، الفرنسية، التركية، الروسية، والإسبانية.
* **آلية استرجاع النصوص (Text Auto-Recovery):** قدرة البوت على استخراج النصوص من الرسائل حتى بعد إعادة تشغيل الخادم المؤقتة، مع إمكانية تحويل النص لأي لغة بضغطة زر.

---

### 📅 7. تنظيم الجداول والمهام الدراسية
* حفظ الجدول الأسبوعي ومواعيد الامتحانات لكل طالب بشكل مخصص ومستقل.
* استرجاع وتعديل الجدول في أي وقت لتنظيم الوقت والاستعداد للاختبارات الأكاديمية.

### 👑 8. لوحة تحكم الإدارة الشاملة (Admin Panel)
* **إحصائيات حية:** عدد الطلاب المسجلين، معدلات الاستخدام، وتوقيت السيرفر.
* **إذاعة الرسائل الأكاديمية (Broadcast):** إرسال تنبيهات جماعية موحدة لجميع طلبة الكلية المسجلين.
* **تصدير التقارير:** تنزيل تقرير كامل بأسماء ومعرفات الطلاب المسجلين بصيغة `.txt`.
* **إشعارات فورية:** تلقي المشرفة إشعاراً فورياً عند انضمام أي طالب جديد.

### ⚡ 9. دعم الملفات الكبيرة حتى 2GB وخادم 24/7
* **Telegram Bot API محلي مدمج:** إمكانية تشغيل خادم محلي يرفع حد استقبال وتحميل الصوتيات إلى **2000 ميغابايت (2GB)**.
* **خادم Flask Keep-Alive مدمج:** خادم ويب مدمج يدعم فحص الصحة (`/healthz` و `/ping`) ويقدم واجهة الـ Mini App والـ API التفاعلي على المنفذ المحدد.

## 🚀 التشغيل المحلي (Local Setup)

### 1. المتطلبات الأساسية
* تثبيت **Python 3.10** أو أحدث.
* تثبيت أداة معالجة الوسائط **FFmpeg** في مسار النظام (System PATH):
  * **Windows:** عبر WinGet بتنفيذ: `winget install Gyan.FFmpeg`
  * **Ubuntu/Debian:** `sudo apt-get update && sudo apt-get install -y ffmpeg`
  * **macOS:** `brew install ffmpeg`

### 2. تنصيب وتشغيل المشروع
```bash
# 1. استنساخ المستودع
git clone https://github.com/ikrame2027zerigui/mybot.git
cd mybot

# 2. إنشاء وتفعيل بيئة افتراضية
python -m venv venv
# لنظام Windows:
venv\Scripts\activate
# لنظام Linux/macOS:
source venv/bin/activate

# 3. تثبيت المكتبات المطلوبة
pip install -r requirements.txt

# 4. نسخ وضبط ملف الإعدادات
cp .env.example .env
```

افتح ملف `.env` واملأ المتغيرات الأساسية:
```env
BOT_TOKEN=your_bot_token_from_botfather
ADMIN_ID=6619712661
PORT=8080
# اختياري: مفاتيح التسريع والذكاء الاصطناعي
GROQ_API_KEY=gsk_...
GEMINI_API_KEY=AIzaSy...
```

```bash
# 5. تشغيل البوت
python BOT.py
```

## 🐳 التشغيل عبر Docker

يحتوي المشروع على ملف `Dockerfile` مهيأ بأحدث بيئة خفيفة معزولة مع FFmpeg ومحرك خادم التيليجرام المحلي:

```bash
# 1. بناء صورة الحاوية
docker build -t mybot .

# 2. تشغيل الحاوية في الخلفية
docker run -d --name mybot-app --env-file .env -p 8080:8080 mybot
```

## ☁️ النشر على منصات السحابة (Render / Koyeb / VPS)

### خطوات النشر على [Render.com](https://render.com):
1. سجّل الدخول واربط حسابك في GitHub.
2. اضغط على **New +** ثم اختر **Web Service**.
3. اختر مستودع المشروع `ikrame2027zerigui/mybot`.
4. في خيار **Environment**، اختر **Docker**.
5. انزل إلى قسم **Environment Variables** وأضف:
   * `BOT_TOKEN`: توكن البوت الخاص بك من BotFather.
   * `ADMIN_ID`: معرّف المشرف في تيليجرام (`6619712661`).
   * `PORT`: `8080` (أو `10000`).
   * `GROQ_API_KEY`: *(اختياري)* لتفريغ الصوت فائق السرعة عبر Whisper خلال 3 ثوانٍ.
   * `GEMINI_API_KEY`: *(اختياري)* لدعم الذكاء الاصطناعي والتلخيص الأكاديمي.
6. اضغط على **Create Web Service**. سيتم بناء وتشغيل البوت تلقائياً وسيعمل على مدار الساعة دون توقف!

## ⚙️ متغيرات البيئة (Environment Variables)

| المتغير | الوصف | إلزامي؟ | القيمة الافتراضية |
| :--- | :--- | :---: | :--- |
| `BOT_TOKEN` | توكن التيليجرام الخاص بالبوت من [@BotFather](https://t.me/BotFather) | **نعم** | — |
| `ADMIN_ID` | معرّف تيليجرام لحساب المشرفة لتلقي الإشعارات والتحكم | لا | `6619712661` |

| `GEMINI_API_KEY` | مفتاح Google Gemini API لدعم الترجمة والتلخيص الأكاديمي المتقدم | لا | — |
| `WEB_APP_URL` | رابط استضافة واجهة الـ Mini App (يُكتشف تلقائياً على Render) | لا | رابط السيرفر التلقائي |

| `TG_API_HASH` | كود Telegram API HASH لدعم رفع الملفات الكبيرة حتى 2GB | لا | `149519bc...` |
| `PORT` | منفذ تشغيل خادم ويب Flask | لا | `8080` |
