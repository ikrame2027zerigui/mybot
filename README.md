## 📖 نبذة عن المشروع

**بوت مُدوِّن الإكرام** هو نظام ذكي مبني بلغة **Python** ومخصص لمساعدة طلبة الجامعات عموماً، وطلبة **كلية العلوم الإسلامية (جامعة الجزائر 1)** خصوصاً. يهدف البوت إلى تيسير التحصيل العلمي عبر الجمع بين تقنيات الذكاء الاصطناعي ومعالجة الصوتيات، وبين العلوم الشرعية والأكاديمية، مما يُغني الطالب عن الاستعانة بتطبيقات متعددة ويوفر له بيئة دراسية متكاملة داخل منصة تيليجرام.

## ✨ المميزات الرئيسية

### 🎙️ 1. التفريغ الصوتي الذكي للمحاضرات
* **معالجة جميع الصيغ:** يدعم الرسائل الصوتية (Voice Notes) والملفات الصوتية الكبيرة بمختلف الامتدادات (`.mp3`, `.m4a`, `.ogg`, `.wav`, `.aac`).
* **تجزئة الصوت التلقائية (Audio Chunking):** استخدام محرك `FFmpeg` لتقطيع التسجيلات الصوتية الطويلة بدقة لمعالجتها دون انقطاع.
* **دقة عالية في التعرف الصوتي:** يعتمد على محرك `Google Speech Recognition` مع ضبط تلقائي لمستويات الضوضاء المحيطة.
* **تصدير مزدوج فوري:**
  * 📄 **مستند Word احترافي (`.docx`):** منسق بغلاف يحمل اسم الطالب، عنوان المحاضرة، تاريخ التفريغ، وملخص نصي منظم.
  * 📝 **ملف نصي خفيف (`.txt`):** ملائم للقراءة السريعة والنسخ المباشر على جميع الهواتف.
* **دعم لغات ولهجات متعددة:** إمكانية التبديل بين العربية الجزائرية (`ar-DZ`)، العربية الفصحى (`ar-SA`)، الإنجليزية (`en-US`)، الفرنسية (`fr-FR`)، والروسية (`ru-RU`).

### 🧠 2. بنك الأسئلة والاختبارات الذاتية
* اختبارات تفاعلية بنظام الخيارات المتعددة (أ / ب / ج) مع تصحيح فوري وتعليل علمي دقيق.
* يشمل تخصصات العلوم الإسلامية الأساسية:
  * ⚖️ **أصول الفقه** (الأدلة، الدلالات، النسخ، التعارض والترجيح).
  * 📜 **مصطلح الحديث** (شروط الحديث الصحيح، المرفوع، الموقوف، المقطوع).
  * 📖 **علوم القرآن** (المكي والمدني، جمع القرآن ورسم المصحف).
  * 🏛️ **القواعد الفقهية** (القواعد الخمس الكبرى وفروعها).
  * 🎯 **مقاصد الشريعة** (الكليات الخمس، مراتب الضروريات والحاجيات والتحسينيات).
  * 🤝 **فقه المعاملات والبيوع المعاصرة**.

### 📚 3. المعجم الفقهي والأصولي الرقمي
* مكتبة مرجعية سريعة مبوبة بأزرار تفاعلية تغنيك عن البحث المطول:
  * القواعد الفقهية الكبرى الخمس مع تطبيقاتها.
  * أدلة أصول الفقه المتفق عليها والمختلف فيها.
  * ضوابط الحديث الصحيح وشروطه الخمسة.
  * أركان القياس وشروطه (الأصل، الفرع، العلة، الحكم).
  * فقه المعاملات المالية الحديثة وضوابطها الشرعية.

### 🌐 4. محرك الترجمة الفورية الشامل
* محرك هجين متعدد الطبقات ومقاوم للحظر التلقائي للطلبات المكثفة.
* ترجمة فورية بين **6 لغات**: العربية، الإنجليزية، الفرنسية، التركية، الروسية، والإسبانية.
* أزرار تبديل سريعة وسهلة بنقرة واحدة أسفل كل نص مترجم.

### 📅 5. المساعد الدراسي وإدارة الجداول
* تسجيل وحفظ جدول المحاضرات الأسبوعي ومواعيد الامتحانات لكل طالب.
* استرجاع الجدول في أي وقت لتنظيم الوقت والاستعداد للاختبارات.

### 👑 6. لوحة تحكم المشرف (Admin Control Panel)
* **إحصائيات حية:** عدد المستخدمين، إجمالي عمليات التفريغ المنفذة، وعدد الطلاب النشطين.
* **إشعارات فورية:** تلقي إشعار تلقائي عند تسجيل أي طالب جديد في البوت.
* **إذاعة الرسائل (Broadcast):** إرسال إعلانات وتنبيهات دراسية موحدة لجميع الطلاب المسجلين بضغطة زر.
* **تصدير التقارير:** تصدير قائمة الطلاب وسجل النشاط كملف `.txt`.

### ⚡ 7. دعم الملفات الكبيرة حتى 2GB وخادم 24/7
* **Telegram Bot API محلي:** إمكانية تشغيل خادم محلي لرفع وتنزيل ملفات الصوت حتى **2000 ميغابايت (2GB)** متجاوزاً حد التيليجرام الافتراضي (20MB / 50MB).
* **خادم Flask Keep-Alive مدمج:** سيرفر ويب خفيف على المنفذ `8080` يبقي البوت متصلاً دائماً على خدمات الاستضافة السحابية.

## 🚀 التشغيل المحلي (Local Setup)

### 1. المتطلبات الأساسية
* تثبيت **Python 3.10** أو أحدث.
* تثبيت أداة **FFmpeg** في مسار النظام (System PATH):
  * **Windows:** عبر WinGet بتنفيذ: `winget install Gyan.FFmpeg`
  * **Ubuntu/Debian:** `sudo apt-get update && sudo apt-get install -y ffmpeg`
  * **macOS:** `brew install ffmpeg`

### 2. تنصيب وتشغيل المشروع
```bash
# 1. استنساخ المستودع
git clone https://github.com/ikrame2027zerigui/mybot.git
cd mybot

# 2. إنشاء وتفعيل بيئة افتراضية
python -m venv venv
# لنظام Windows:
venv\Scripts\activate
# لنظام Linux/macOS:
source venv/bin/activate

# 3. تثبيت المكتبات المطلوبة
pip install -r requirements.txt

# 4. ضبط متغيرات البيئة
cp .env.example .env
```

افتح ملف `.env` وضع توكن البوت الخاص بك من [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=8819830801:AAE...
ADMIN_ID=6619712661
PORT=8080
```

```bash
# 5. تشغيل البوت
python BOT.py
```

## 🐳 التشغيل عبر Docker

يحتوي المشروع على ملف `Dockerfile` مهيأ بالكامل يشمل بايثون، وFFmpeg، ومحرك خادم تيليجرام المحلي:

```bash
# بناء صورة Docker
docker build -t mybot .

# تشغيل الحاوية في الخلفية
docker run -d --name mybot-app --env-file .env -p 8080:8080 mybot
```

## ☁️ النشر على منصات السحابة (Render / Koyeb / VPS)

### خطوات النشر على [Render.com](https://render.com):
1. سجّل الدخول واربط حسابك في GitHub.
2. اضغط على **New +** ثم اختر **Web Service**.
3. اختر مستودع المشروع `ikrame2027zerigui/mybot`.
4. في خيار **Environment**، اختر **Docker**.
5. انزل إلى قسم **Environment Variables** وأضف:
   * `BOT_TOKEN`: توكن البوت الخاص بك من BotFather.
   * `ADMIN_ID`: معرّف المشرف في تيليجرام (مثل: `6619712661`).
   * `PORT`: `8080`.
6. اضغط على **Create Web Service**. سيتم بناء وتشغيل البوت وسيعمل تلقائياً على مدار الساعة!

## ⚙️ متغيرات البيئة (Environment Variables)

| المتغير | الوصف | إلزامي؟ | القيمة الافتراضية |
| :--- | :--- | :---: | :--- |
| `BOT_TOKEN` | توكن التيليجرام الخاص بالبوت من [@BotFather](https://t.me/BotFather) | **نعم** | — |
| `ADMIN_ID` | معرّف تيليجرام لحساب المشرف لتلقي الإشعارات والتحكم | لا | `6619712661` |
| `GEMINI_API_KEY` | مفتاح Google Gemini API لدعم الترجمة والذكاء الاصطناعي | لا | — |
| `TG_API_ID` | كود Telegram API ID لدعم ملفات حتى 2GB | لا | `35521120` |
| `TG_API_HASH` | كود Telegram API HASH لدعم ملفات حتى 2GB | لا | — |
| `PORT` | منفذ تشغيل خادم ويب Flask | لا | `8080` |
